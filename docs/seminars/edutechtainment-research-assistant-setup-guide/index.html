What Is It?

The EduTechTainMent Research Librarian is an interactive AI skill for Claude or any other AI Agents that turns a conversation into a research-methodology consulting session. It walks a researcher, in any discipline, from a rough idea through to a fully structured, evidence-grounded, submission-ready study protocol.

Created and maintained by (EduTechTainMent](https://waga43.github.io/weblog)

Important

Remember: You can outsource your thinking to AI, but NEVER outsource your understanding to AI.

Note

AI can give you answers fast enough to simulate understanding.

Caution

It is hard to understand something if you haven’t thought about it.

AI is the living proof of that, it can think for ages and come up with (a) suprisingly stupid idea(s).

What Can This Skill Do?

At its core, the skill helps you:

  • Scope the type of study and discipline
  • Build or critically refine a formal, answerable research question
  • Break the question down using the correct framework (PICO, PICOC, PECO, PEO, CoCoPop, SPICE, SPIDER, or PCC), with a search for precedent studies that used the same framework
  • Construct syntax-validated search strings for Boolean-query academic databases, plus guidance for AI-native discovery tools (Consensus, Inciteful, Research Rabbit, Semantic Scholar)
  • Classify study variables and map them to the statistically correct test using an interactive decision-tree conversation
  • Produce a verified reading list with every citation checked
  • Assemble a final deliverable document (Markdown, Word, or PDF)

The skill is:

  • interactive by design - it stops after every major step and asks for your input,
  • critical by construction - it pushes back on weak inputs rather than rubber-stamping them, and
  • Has zero tolerance for fabrication - no invented citations, DOIs, statistics, or cost figures.

Which Version Should I Install?

The archive contains three versions. Here is a quick decision guide:

If you want… Install
Just a database-search-string builder and a PICO-family breakdown helper, with critical pushback on your inputs v1
The above, plus help turning a question into rigorous, literature-justified SMART objectives v2
The above, plus question brainstorming, realistic feasibility/timeline/cost estimation, an honest limitations critique, and a full IRB-ready protocol with detailed workflow documentation v3 (recommended)
A lightweight tool for a single-session task v1
A tool to take you all the way to a submittable, collaborator-ready research protocol v3
Something tuned for researchers in lower-resource settings (e.g. Nigeria/Africa) needing realistic cost/timeline planning v3

If you are not sure, install v3. Every capability in v1 and v2 is still present in v3.

5-Minute Setup Guide

Step 1: Extract the Archive

Extract the contents of EduTechTainMent_Research_Assistant.zip using any archive software - the default Windows built-in extractor, WinRAR, or 7-Zip all work.

It will extract into a folder containing 4 files:

  • edutechtainment-research-librarian-v1.skill
  • edutechtainment-research-librarian-v2.skill
  • edutechtainment-research-librarian-v3.skill
  • README.md

Step 2: Read the README.md File

Open README.md using a Markdown reader such as Typora. You can also search Google to download and install other free Markdown editors. The README explains in detail what each version can help you with. It is recommended to go through it to fully understand what you can achieve with this AI agent skill.

Step 3: Install One Skill

All you need to do is install one of the three .skill files. Start by installing v3 of the Research Librarian by following the same installation steps as outlined in the README.

Step 4: Restart Claude Desktop

You may need to restart your Claude Desktop app before you can invoke the newly installed skill.

Step 5: Start Using It

Manually invoke the skill using the forward slash command /, then type your research question. If you do not have one yet, no problem, the skill is designed to help you develop one.

How It Works

The skill is designed to be interactive. You are the pilot; the AI is the copilot. You are the expert with domain expertise; the AI is your research assistant.

The skill will help you design and conceptualize your entire research workflow:

  1. Ideation — from a rough topic to a scoped research question
  2. Framework selection — PICO, PICOC, PECO, PEO, CoCoPop, SPICE, SPIDER, or PCC, with precedent citations
  3. Search strategy — syntax-validated Boolean queries for PubMed, Scopus, Google Scholar, ScienceDirect, IEEE, plus AI-native tools (Consensus, Inciteful, Research Rabbit)
  4. SMART objectives — literature-grounded, Specific, Measurable, Achievable, Relevant, and Time-bound (v2+)
  5. Variable classification — dependent/outcome (primary and secondary), independent/input, and confounding variables, grounded in published research
  6. Statistical analysis recommendation — interactive decision tree based on variable types
  7. Feasibility and costing — realistic timeline and budget bands, with region-specific guidance (v3)
  8. Limitations critique — evidence-based, with mitigation plans (v3)
  9. Study protocol — full IRB-ready document with correct reporting guideline, tense convention, and mandatory bibliography (v3)
  10. Workflow documentation — a detailed, readable record of every decision made, not a condensed summary

What This Skill Will Not Do

  • It is a methodology and literature-search assistant, not a substitute for a qualified statistician, a research ethics committee, or a professional research methodologist
  • It will never fabricate citations, DOIs, PMIDs, author names, statistics, database syntax, or cost figures
  • Recommendations should be independently verified before submission to a funding body or ethics committee
  • Citations and framework precedents are verified at the time of the conversation; re-verify close to your actual submission date

Important Note

This skill will not work perfectly for you if you do not act like the pilot who has domain expertise. It is designed with anaesthesiologists as the primary focus, but is general-purpose by design.

P.S. You can reach out if you have any questions or challenges regarding the use.
